# Installation

## Current status

LeetSensei is still in the planning/scaffold stage. A working extension package is not available yet.

## Intended development workflow

1. Install a supported Node.js LTS version.
2. Clone this repository.
3. Install dependencies using the package manager and lockfile that will be committed.
4. Run the build and tests.
5. Load the development build in the browser's extension developer mode.

Exact commands will be added after Phase 1 chooses the build system and creates a manifest.

## Browser notes

- Chrome and Brave are expected to use Chromium's extension developer mode with a local build.
- Firefox development and signed-release workflows differ and will have separate instructions.
- Store installation instructions will be added after packages exist and store review requirements have been checked.

This planning document does not imply installation is currently supported.
