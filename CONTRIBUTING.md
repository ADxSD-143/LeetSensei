# Contributing

LeetSensei is being developed in small, testable phases. While the extension foundation is not implemented, contributions may focus on specification, design discussion and prototypes.

## Before starting
1. Read README.md, ROADMAP.md, docs/TDD.md and docs/SECURITY.md.
2. Search issues and pull requests before opening a new issue.
3. Discuss substantial changes in an issue before implementing them.
4. Never commit access tokens, private data or credentials.

## Development expectations
- Keep changes focused and test behavior changes.
- Isolate browser-specific behavior behind adapters.
- Never silently overwrite an existing user file.
- Request and document minimal permissions.
- Do not add telemetry or analytics.
- Document assumptions about LeetCode page structure and revalidate them when the site changes.

## Pull requests
Include what changed and why, how it was tested, relevant issue links, screenshots for UI changes, and compatibility or migration notes.

Do not submit credentials, proprietary code, or fabricated data presented as real submissions.
